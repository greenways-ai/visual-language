Greenways OS / installation 02

Capabilities stay visible.

The extension is the browser shell and browser capability provider. Greenways OS remains a portable workspace model; native custody and long-running jobs stay optional through greenwaysd.

Runtime providers

Providers perform named effects. Packages and sandboxed Hara code never receive direct browser authority.

Key custody

The Keyring presents both levels in one place without pretending browser storage and OS-backed custody are equivalent.

Human decisions

Privileged effects cross a narrow broker. The chosen policy is checked before the provider runs and the decision is attached to the receipt.

Durable state

The service worker may stop at any time. Frames reconstruct from serialisable workspace state rather than relying on a permanently alive background process.
