Day and night are two authored states of one place. The accepted day master establishes camera, architecture, scale, materials, routes, and responsive crop. The night master keeps that spatial contract and changes only illumination, atmosphere, peripheral movement, and natural behaviour.

## Runtime use

`ThemedArtwork.astro` still selects the state that follows the page theme. Editorial pages and catalogues should also provide explicit Day, Night, or Compare controls whenever the pair itself is the subject.

```astro
<ThemedArtwork
  light="/artwork/hoplite/open-gate-day.webp"
  dark="/artwork/hoplite/open-gate-night.webp"
  lightMobile="/artwork/hoplite/open-gate-day-mobile.webp"
  darkMobile="/artwork/hoplite/open-gate-night-mobile.webp"
  lightAlt="A rabbit paused in a cyan mosaic gate by day"
  darkAlt="A rabbit sheltered inside the same gate at night"
/>
```

## Failure mode

A dark overlay on the day image is not a night master. Night requires physically located light, changed reflections, credible shadow, and a natural state that belongs to the same architecture.
