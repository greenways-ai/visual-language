## Before changing a motif

Confirm that the change is intended for the canonical project identity rather than an exploration study. A project mark change affects favicons, shared headers, social cards, documentation, and consumer projects.

## Pull request scope

A visual-system pull request should include:

- source geometry or token changes;
- regenerated canonical assets;
- relevant documentation updates;
- tests for deterministic rules;
- screenshots or preview links for visual judgement.

## Commands

```bash
npm install
npm test
npm run build
```

## Artwork changes

Preserve accepted camera and architectural logic when editing a day/night pair. New native masters should be followed by responsive WebP generation and catalogue review.

## Accessibility

Verify contrast, keyboard navigation, focus visibility, meaningful alternative text, reduced-motion behaviour, and mobile layout before merge.
