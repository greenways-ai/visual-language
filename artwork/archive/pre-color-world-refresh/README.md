# Pre-colour world refresh archive

This archive preserves the World / WWW and Tahto raster artwork that preceded
the saturated mosaic-world and purple–crimson Tahto refresh.

- `www/masters`: 16 original day/night PNG masters
- `www/site`: 32 original desktop/mobile WebP derivatives
- `tahto/masters`: 16 original day/night PNG masters
- `tahto/site`: 32 original desktop/mobile WebP derivatives

The files are retained as source history and are not copied into the public site.
